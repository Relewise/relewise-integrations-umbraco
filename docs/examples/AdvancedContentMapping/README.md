# Advanced content mapping example

The buildable examples now live in the maintained
[Relewise.DemoStorefront](../../../samples/Relewise.DemoStorefront/README.md#mapping-examples).
It includes custom entity mapping, asynchronous field converters and Block List/Grid
text extraction in a runnable Umbraco site.

The [legacy Content mapping guide](../../custom-content-mapping.md) remains useful
for existing integrations; new implementations should use the
[entity mapping API](../../entity-mapping.md).
